# CyberSecurityModelBenchmarks
Bu repo Türkçe siber güvenlik alanında veri seti oluştrulmak ve model eğitimine katkı sağlanmak için hazırlanmıştır. 
[https://huggingface.co/datasets/sk75/Turkish_Cyber_Security_CVE_Question_Answer] veriseti ile eğitilen [https://huggingface.co/sk75/qwen3.5-4b-siber-guvenlik-tr-merged] modelinin diğer modellerin base haline göre karşılaştırılması yapılmıştır.
