## Cloning and opening the notes

This repository is a portable [Obsidian](https://obsidian.md/) vault. Its note links and Obsidian configuration use paths relative to the repository root, so the vault can be cloned into any directory.

~~~sh
git clone <repository-url>
cd how_llm_works_from_transformers_to_implementation
~~~

Then open Obsidian, select **Open folder as vault**, and choose the cloned repository folder.

No setup script or fixed installation path is required. To keep the vault portable, use Obsidian wiki links such as **[[03_03 Tokenization]]** or relative Markdown links. Avoid links beginning with **/home/**, **/Users/**, a Windows drive letter, or **file://**.
